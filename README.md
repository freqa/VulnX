## VulnSight – Automated Web Application VAPT & Security Assessment Platform

**VulnSight** is an automated web application security assessment platform designed to identify, analyze, and report security vulnerabilities in web applications. The system aims to simplify the Vulnerability Assessment and Penetration Testing (VAPT) process by bringing reconnaissance, automated security scanning, vulnerability analysis, risk assessment, evidence collection, and report generation into a single platform.

The user can provide a target web application or authorized domain, after which VulnSight performs automated reconnaissance and security checks. The platform can integrate security-testing tools such as **Nmap** and **OWASP ZAP** to identify potential vulnerabilities and security weaknesses. It also evaluates common web-security issues such as insecure HTTP headers, SSL/TLS configuration problems, cookie security weaknesses, exposed services, and other detectable application-level security issues.

The results are collected and analyzed by the backend, where vulnerabilities can be categorized according to their severity and potential impact. The platform presents the findings through an interactive dashboard, allowing users to understand the discovered vulnerabilities, affected components, supporting evidence, and recommended remediation measures.

A major objective of VulnSight is to make security assessment more **structured, repeatable, and accessible** while reducing the amount of manual effort involved in conventional VAPT workflows. The system can also generate a comprehensive security assessment report that can be used by developers, students, security researchers, and authorized security professionals to understand and address identified weaknesses.

### Key Features

* Automated target reconnaissance
* Network and service discovery using Nmap
* Web application scanning using OWASP ZAP
* HTTP security-header analysis
* SSL/TLS security checks
* Cookie security analysis
* Vulnerability identification and classification
* Risk/severity assessment
* Evidence collection
* Remediation recommendations
* Interactive security dashboard
* Automated security assessment report generation

### Objective

The primary objective of VulnSight is to develop a centralized platform that automates major stages of web application security assessment and presents the results in an understandable and actionable format.

**VulnSight is intended to be used only for systems for which the user has explicit authorization to perform security testing.**
